# Ip Calculator API 🚀

The aim of this project is to develop an API that consolidates **all essential IP address calculations** into a single, easy-to-use service. This API provides network administrators and developers with a streamlined solution for handling IP conversions, subnetting, address classification, and more—all in one place.

## ✨ Features

### IP Address Conversion

-   Convert IP address to **IPv4, binary, decimal**, and **CIDR (/X) notation**

### Network Information Retrieval

-   Determine **network address**
-   Calculate **broadcast address**
-   Identify the **number of hosts** and their addresses

### Subnetting

-   Generate **subnets**
-   Support **VLSM (Variable Length Subnet Mask) method** for subnetting

### IP Classification

-   Determine the **class of an IP address** (A, B, C, etc.)
